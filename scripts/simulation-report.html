Over 14 simulation runs, we iterated on three layers: soul files (agent personality), prompt structure (silence discipline), and engine architecture (nano pre-filter claim loop). The result is a conversation engine that produces natural, paced dialogue where agents speak only when they have something uniquely valuable to add.

Architecture Changes

User message arrives | v CLAIM LOOP (max 4 rounds): |-- All eligible agents -> nano filter (gpt-5.4-nano, parallel) | Tools: speak(reason) | stay_silent() | ~200ms, ~$0.0001 per call | |-- Candidates who said speak() | First candidate -> full inference (gpt-5.4 or 5.4-mini) | Message added to conversation | |-- Remaining agents re-evaluate with nano | (seeing the new message - may change mind) | v-- Repeat until no one wants to speak

Key Design Decisions

engine.tsReplaced parallel-evaluate-all with sequential claim loop. Agents "riff" off each other naturally.
openai.tsExtracted shared OpenAI calling logic. Both /api/chat and simulate.ts use identical codepath.
souls/*.md8 soul files with Core, Voice, Lens, Rules, and Anti-patterns. Immutable personality layer.
identities.tsIdentity layer (name, age, industry) separated from soul. DB-persisted, per-user customizable.
prompts.tsRewrote buildFilterPrompt() for nano calls. Strengthened silence-by-default rules. Added tool usage enforcement.

Iteration Timeline

Round 1 — Baseline (Pre-Soul)

Runs 1-4. Flat roster.ts definitions. All members spoke every turn. Identity bleed rampant (agents answered as the user). Phase transitions never fired. Avg 40 messages/session.

Round 2 — Soul Files + Identity Separation

Runs 5-8. Created 8 soul .md files with anti-patterns ("You are NOT the user"). Identity bleed eliminated immediately. Avg 28 messages. Phase transitions started working via move_to_phase tool.

Round 3 — Silence Discipline + Prompt Tuning

Runs 9-14. Rewrote member prompt to lead with "DEFAULT ACTION: stay_silent." Added pacing rules. DA verbal tic fixed. Avg 25 messages. Warmup turns now have only Maude speaking.

Round 4 — Nano Pre-Filter Claim Loop

Final runs. gpt-5.4-nano decides speak/silent before full inference. Sequential claim with re-evaluation. Agents "change mind" after seeing others speak. Avg 19 messages. Natural riffing between agents.
